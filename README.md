## ✦ About ATHAR

ATHAR is a contemporary fashion e-commerce website designed to combine premium visual aesthetics with an engaging and intuitive shopping experience.

Built with a focus on elegant typography, refined layouts, smooth interactions, and a distinctive dark-and-gold visual identity, the platform transforms browsing fashion products into an immersive digital experience.

Beyond its visual presentation, ATHAR incorporates interactive shopping features that help users explore products, manage their cart, save favorites, and connect directly through WhatsApp.

**ATHAR® — Leave Your Mark.**

##  Key Features

###  Interactive Shopping Experience

* Browse fashion products through an elegant, organized interface.
* Explore product details and pricing.
* Add products directly to the shopping cart.
* Manage cart items and build a personalized selection.
* Save favorite products for quick access.

##  Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm (included with Node.js)
* Git

### Installation

**1. Clone the repository**

```bash
git clone <https://github.com/MOHAMED54353/Athar>
```

**2. Navigate to the project directory**

```bash
cd <Athar>
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the application.

### Production Build

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
